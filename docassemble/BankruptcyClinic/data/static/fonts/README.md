# Archivo

`archivo-latin.woff2` and `archivo-latin-ext.woff2` are the Archivo variable
font — weight 100–900, width 62–125% — subset to Latin and Latin Extended-A.
Archivo is here because it stays readable when condensed, which is what the
grey section bands and the small form labels need, and because it is the face
the project site already uses.

The files are served from this package rather than from Google Fonts. An
interview that collects Social Security numbers and creditor lists should not
make the filer's browser announce itself to a third party on every screen.
